# Contributing to RenWeave

Thank you for helping improve RenWeave.

1. Open an issue for substantial behavior or architecture changes before implementation.
2. Create a focused branch and keep unrelated changes out of the pull request.
3. Add or update tests for observable behavior.
4. Run `python -m unittest discover -s tests -v` and `python -m compileall -q src tests`.
5. Explain user-facing changes, safety implications, and token-cost implications in the pull request.

Never commit API keys, proprietary game scripts, model responses containing private data, generated workspaces, or translation packages. By contributing, you agree that your contribution is licensed under GPL-3.0.
